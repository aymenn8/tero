# Tero 0.0.2

A clearer installation and a more native Mac experience.

- A branded installer with the Tero disk icon, a Retina background and a direct drag into Applications.
- Native app icons remove the large white frame on recent macOS versions.
- Settings appear in the Dock while open. Clicking Tero brings back your last Settings page, including minimized windows.
- Closing Settings keeps Tero available in the menu bar. Opening Tero manually shows Settings; login launches remain in the background.

Requires macOS 14 or later. Tero is in beta.
