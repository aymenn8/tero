## What's new

- Ask is now a single entry point for questions and product recommendations.
- Action bubbles show a small icon before each mode name, including on the home row and in Clipboard actions.
- A new Tero logo and app icon.
- Tero Pro is now €7.99 per month.

## Changes

- File actions focus on what Tero does best: Rename, Batch rename, Move files and Summarize. Compress, Extract archive, image Convert/Resize/Compress, Extract text, Merge PDFs, Extract PDF pages and document Convert were removed because macOS already handles them.

## Improvements

- Smoother typing in Ask and faster streaming answers: text measurements are reused instead of recalculated.
- Faster action suggestions and Clipboard browsing.
- Fixed a file action closing a newer Tero window, and earlier requests are cancelled when you start a new correction or reply.
