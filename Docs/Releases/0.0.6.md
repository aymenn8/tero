## Fixes

- Summarize and Rename now read DOCX, XLSX and PPTX text locally without requiring LibreOffice.
- File conversion offers text exports, text-only PDFs and simple DOCX files. Office images, charts and original layout are excluded; spreadsheets use saved values without recalculating formulas. Legacy DOC/XLS/PPT, ODF and RTF formats are no longer offered.
- The welcome tour keeps its intended window size through page changes and replay. Clicking the Dock icon resumes an open tour without restarting a closed one.
- Ask handles completed web answers more reliably.
- Refine a result in a small input below the existing answer. The answer stays visible while you request changes, with Cancel and Return to apply them.
- Ask, Shop, Clipboard and reading results remain open when focus moves to another app.
