## What's new

- A guided first launch to discover Tero, connect your account and set your shortcut.
- Smoother action bubbles and a more consistent Ask, Explain and Shop experience.
- Ask grows with its response, and loading animations keep text in place.
- Create, refine and test personal habits with a simpler editor and an editable name.
- Personal file habits can rename files or move them to a chosen folder.
- Personal habits participate in recommendations alongside Tero's built-in actions.

## Improvements

- More useful context for recommendations, including the focused writing field.
- A smaller Jev ranking prompt and more time for the first recommendation after inactivity.
- Development diagnostics show the ranking request, scores and timing.
