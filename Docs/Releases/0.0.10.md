## What's new

- **Ask AI about any selection.** Select text, press your Tero shortcut, choose **Ask AI** and type what you want.
  - In a text field, Tero writes: your request rewrites the selection and the result replaces it.
  - Anywhere else, Tero explains: the answer opens in a card you can copy or refine.
- Ask AI is always the third bubble for text selections, and you can give it its own shortcut in Settings → Shortcuts.

## Changes

- Explain moves to the second page in text fields, and Correct to the second page in read-only text. Search still finds every action.
