# Security policy

Please don't report security issues in public issues.

Email **aymen@kadri.live** with a description, steps to reproduce and the affected version. You'll get an answer within a few days, and a fix or mitigation will be released as soon as possible. Please give us reasonable time before any public disclosure.

In scope: the macOS app, its handling of API keys and selected content, the update mechanism, and the Supabase functions in this repository. API keys are stored in the macOS Keychain; if you find a way they can leak, that is always in scope.
